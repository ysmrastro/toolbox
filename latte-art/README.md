# ラテアート練習（試作）

iPhone をミルクピッチャーに見立てて傾けると、上から見たカップにミルクが注がれ、
ラテアートが描かれる。HTML と JS だけで動く（外部ライブラリなし）。

**試作の目的は「傾けて注ぐ操作が、手の感触として成り立つか」を確かめること。**
描ける模様はまだハートまでで、ロゼッタは描けない（下の「ロゼッタが描けない」）。

## 操作

| 操作 | 方法 |
|---|---|
| 傾けて注ぐ（iPhone） | 「傾けて注ぐ」を押し、画面が見える角度で構える。その角度から手前に倒す（上の辺を下げる）と注げる。6°〜32°で注ぐ量が 0〜最大 |
| ウィグル | 左右に傾けると注ぐ点が横に動く（22°で最大、カップの直径の 18%） |
| **高さ** | **親指をカップに置いているあいだは注ぎ口が液面ぎりぎり、離すと高い位置**。置いた指の位置が注ぐ点になる |
| 切り抜き | 置いた指を奥へ素早く滑らせる（速く動く流れは潜る）。指を離すと高い位置に戻る |
| 押して注ぐ（PC・確認用） | カップを押しているあいだ、マウスの位置に注ぐ。量はスライダー、高さはチェックボックス |

- **傾きは `deviceorientation` の `beta`（前後）と `gamma`（左右）**。iOS は
  `DeviceOrientationEvent.requestPermission()` の許可が要り、**ボタンを押した処理の中でしか呼べない**。
  HTTPS でないと値が届かない（GitHub Pages なら満たす）
- **画面の向きは Web ページから固定できない**（iOS は `screen.orientation.lock` 非対応）。
  傾けると横向きに回ってしまうので、コントロールセンターで縦向きに固定してもらう案内を画面に出している
- **注ぐ点の前後の移動と高さはセンサーから取れない**。加速度を2回積分すると誤差がすぐ膨らむ。
  取れるのは角度だけなので、どちらも指で表す。高さを指に割り当てたのは、白が浮くかどうかの
  第一の条件が高さだから（下の「白が浮くか沈むか」）
- 本物ほど深く倒すと画面が見えなくなるので、浅い角度（32°）で最大に届くようにしてある

## モデル

### 白が浮くか沈むか（`pour.js`）

**作者（初心者）の感覚ではなく、解説に書かれていることに従う**（下の「出典」）。
v0.1 では「勢いがないと沈む」としていたが、実際は逆だった（指摘を受けて調べ直した）。

| 解説に書かれていること | 規則 |
|---|---|
| 高い位置から注ぐと、勢いがついてクレマを突き抜け、潜る。最初はこれで茶色の土台を作る | 指を置いていない（高い）ときは必ず沈む |
| 注ぎ口を液面ぎりぎりまで下げると、横に流れて泡が表面に乗る。白が出るのはここだけ | 指を置いている（低い）ときだけ白が浮きうる |
| 下げるのはカップが半分〜3/4 入ってから。最初に高く注いで沈めないと、泡が混ざって全体が濁る | カップの量 45%→60% で浮き始める。浅いうちに低く注ぐと、沈んだミルクの濁りを強める |
| 流量は弱すぎると泡を押し広げられず、強すぎると模様が崩れて沈む | 注ぐ量 0.1→0.25 で浮き始め、0.7→0.92 で沈んでいく |
| 切り抜きは、流量を絞り、持ち上げながら横切る | 指を速く滑らせると潜る（`DIVE_SPEED`）。指を離すと高くなって沈む |

沈んでいるときは、画面に理由（高い・まだ浅い・勢いが強い・弱い）を出す（`phase()`）。

### 液面の流れ（`fluid.js`）

上から見た液面の2次元流体を、Stable Fluids で WebGL2 の上で解く
（速度場 192×192、染料 512×512、圧力のヤコビ反復 30回）。

**注ぐ点を湧き出し口にしてある。** 非圧縮の射影をそのままかけると、外へ広がる流れ（発散）が
すべて消され、注いでも白が広がらない。注ぐ点で発散の目標値を正にし、同じ量をカップ全体から
一様に吸い込ませる（閉じたカップでは湧き出しの合計が0でないと解が無いため）。

**泡は濃さではなく厚みとして運ぶ。** 液面が伸びる（発散が正の）ところでは薄くなる。
注ぐ点の中身は「湧き上がってくるもの」に置き換える。白が浮いているときは泡、
潜っているときは下の茶色い液。

染料のチャンネルは R＝泡の厚み、G＝クレマのまだら、B＝沈んだミルクでクレマが明るくなった度合い。

### 調整値（`app.js` の `T`）

物理量ではなく、画面で見ながら決めた値。`window.LATTE.tune` から書き換えて見比べられる。

| 値 | 既定 | 何か |
|---|---|---|
| `SOURCE` | 22 | 湧き出しの強さ [1/秒]。描く段階の流量は満たす段階の約3倍になる（Barista Hustle）ので、ぎりぎりから注いだときに強く押し広げる |
| `SOURCE_SUNK` | 0.35 | 沈んでいるあいだの湧き出しの割合 |
| `DRAG` | 0.1 | 注ぐ点の動きに液面が引きずられる割合 |
| `MOVE_MAX` | 0.8 | 引きずる速さの上限 [uv/秒] |
| `JET` | 0 | 注ぎ口の向きへの勢い（下記の理由で 0） |
| `DIVE_SPEED` | 0.6 | 指（マウス）で注ぐ点をこれより速く動かすと潜りやすい [uv/秒]。左右の傾きのウィグルは数えない |
| `FOAM` | 1.2 | 注ぐ点で湧き上がる泡の厚み |

**引きずる力（`DRAG`）は弱くしてある。** 強くすると、液面全体が大きな渦を1組巻いて、
描いた白がまるごと奥へ押し流される（細い流れが1本の筋を引く、という本物の切り抜きにならない）。

## ロゼッタが描けない

決まった注ぎ方（`window.LATTE.drive()` で入力を与える）で、次を試したがどれも葉が分かれなかった。

| 試したこと | 結果 |
|---|---|
| 注ぎ口の向きへの勢い（`JET`） | カップ全体に大きな渦が1組できて、模様が流れるだけ |
| 揺らす動きで液面を引きずる（`DRAG` を強く） | 揺らすたびに渦ができ、白が大きな塊2つになる |
| 速く動くと潜る（`DIVE_SPEED`） | 揺らしている間は白が乗らず、薄い筋が2本残るだけ |
| 泡を厚みとして運び、注ぐ点の中身を置き換える | 同上。葉の間に茶色の筋が挟まらない |
| 中央に白の土台を作ってから揺らす | 大きな左右対称の渦になる |

細い層が積み重なる前に、運ぶ計算（semi-Lagrangian の線形補間）で模様がぼける。
次に試すなら、染料の運び方を BFECC / MacCormack にして拡散を減らすこと。
または、泡を格子ではなく粒子で持つ形に変えること。

## 確かめ方

```bash
npm run test:latte-art   # 注ぐ規則（pour.js）のテスト
python3 -m http.server 8899
# http://localhost:8899/latte-art/ を開き、DevTools で:
#   （ogp-source.html を開くと、recipes.js の HEART を流したカップが出る）
```

`LATTE.drive(フレーム数, i => ({ x, y, flow, low }))` は入力を決めて 1/60 秒ずつ進め、最後に1回描く。
`recipes.js` の `HEART` が解説どおりのハートの注ぎ方（高く注いで半分まで → ぎりぎりから白を乗せる
→ 素早く横切る）で、`ogp-source.html` もこれで描いている。

## 出典

白が浮くか沈むか・注ぎの手順は次の解説に従った（2026-10 に参照）。

- [Prima Coffee: The Complete Guide to Pouring Latte Art](https://prima-coffee.com/blog/the-complete-guide-to-pouring-latte-art/)
  — 高さ 7〜8cm からゆっくり注いで沈める段階と、注ぎ口を液面ぎりぎりにして描く段階。
  切り抜きは流量を絞り、持ち上げながら横切る。カップは 30〜45° 傾けて始め、満ちるにつれて平らに
- [Barista Hustle: Flow Rate, Width, & Height](https://www.baristahustle.com/?p=2331)
  — 満たす段階の流量 10〜20 ml/秒。弱すぎると流れが途切れ、強すぎると表面が濁る。
  描く段階の流量は満たす段階の約3倍
- [Clive Coffee: Latte Art: How to Pour a Heart](https://clivecoffee.com/blogs/learn/latte-art-how-to-pour-a-heart)、
  [The Top 6 Latte Art Mistakes](https://clivecoffee.com/blogs/learn/the-top-6-latte-art-mistakes)
  — カップが半分〜3/4 になったら注ぎ口を液面に近づける。高すぎると泡が沈んで茶色くなる
- [Tasting Table: How To Pour A Rosetta](https://www.tastingtable.com/1601190/how-to-pour-rosetta/)
  — ロゼッタは液面に近い位置で揺らし始め、手前に引き、最後に奥へ抜いて軸を作る
