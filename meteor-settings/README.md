# 流星撮影セッティング

機材構成・流星群・撮影目的を選ぶと、理論に基づいた露出時間・F値・ISO と、その設定で
写せる暗さ（到達等級）・火球を白飛びさせない限界・1コマに収まる確率を算出する Web アプリ。

- URL: https://ysmrastro.github.io/toolbox/meteor-settings/
- フレームワーク不使用の静的ファイルのみ。GitHub Pages で動作。
- PWA 対応（ホーム画面に追加してオフラインでも動く）。撮影地が圏外でも使える。
- スマホ・タブレット・PC に対応。画面幅で3つのレイアウトを切り替える。

## レイアウト

| 画面幅 | レイアウト |
|---|---|
| 〜699px（スマホ） | 1カラム480px＋下部タブ。上部に推奨値のサマリーを常時表示 |
| 700〜1099px（タブレット縦） | 1カラム680px＋下部タブ。固定バーは全幅に伸ばし中身のみ中央寄せ |
| 1100〜1499px（タブレット横・PC） | 2カラム。左に機材と条件（各カラム内は2段組）、右に結果を追従表示。タブとサマリーは非表示 |
| 1500px〜（大画面PC） | 3カラム（機材 / 条件 / 結果） |

1100px 以上ではタブ切り替えが不要になり、入力を変えると右の結果が即座に更新される。
「計算の前提と出典」は狭い画面ではボトムシート、広い画面では中央のダイアログ（Escapeで閉じる）。

## バージョン

アプリバー右上とⓘシートの末尾に、バージョンと更新日を小さく表示している。

| 変更の種類 | 上げ方 |
|---|---|
| バグ修正 | パッチを +0.0.1 |
| 機能追加 | マイナーを +0.1（パッチは 0 に戻す） |
| メジャー | よほどの変更のときだけ |

更新日時は `YYYY-MM-DD HH:MM`。アプリバーでは3段（バージョン／日付／時刻）で表示する。

リリース時に更新する3か所:

1. `data.js` の `MS_DATA.appVersion`
2. `data.js` の `MS_DATA.appUpdated`（更新日）
3. `sw.js` の `CACHE`（`meteor-settings-vX.Y.Z`）— キャッシュを確実に入れ替えるため

## 引っぱって更新（pull-to-refresh）

ブラウザ標準の pull-to-refresh は、PWA を standalone で起動すると存在しない（iOS）か
抑制されるため、`app.js` の `setupPullToRefresh()` で自前実装している。
CSS の `overscroll-behavior-y` は `contain`（`none` ではない）にして、
ブラウザ標準の動きと二重にならないようにしている。

- 画面上端（`scrollY <= 0`）で下に引っぱるとインジケーターが出る
- 70px 以上引っぱって離すと更新。それ未満なら元に戻る
- スライダー操作中とⓘシート表示中は反応しない
- 更新時は Service Worker の `update()` を先に走らせ、待機中の版があれば
  `SKIP_WAITING` を送って取り込んでから `location.reload()` する
- タッチのないPCでは使えないため、ⓘシート末尾に「更新を確認」ボタンを置いている

## 出典とクレジット

### 撮影設定の理論

計算は **friend_camera** 氏の記事
[「流れ星の撮り方｜F値とISOを『理論』で決めるペルセウス座流星群の撮影設定ガイド」](https://note.com/brave_godwit4798/n/n938a74b50144)
の付録A（8つの計算式）と本文の各表をそのまま実装したもの。**著者の許諾を得て公開**している。

理論・数値の考案はすべて原著者によるもので、本ツールはその計算を機材構成・流星群・
撮影目的に一般化して自動化したもの。

### 夜空の明るさ（光害）データ

**David Lorenz** 氏の
[World Atlas of the Artificial Night Sky Brightness（2025年版）](https://djlorenz.github.io/astronomy/lp/)
から日本周辺を切り出して `lp-tiles/` に同梱している。
元となる夜間光データは NOAA VIIRS の年平均雲なし夜間光
（Earth Observation Group, Colorado School of Mines）。

**重要**: この値は「天頂（真上）の人工光による輝度」のモデル計算値であり、
**Bortle スケールではない**。原著者は自サイトで、地図を他サイトで使う場合に
Bortle スケールと混同しないよう明確に求めている。UI と README の両方でこれを明記している。

## カメラを向ける方向の扱い

方位と高度を入力すると、次の3つを計算する。

### 放射点からの離角（誤差なし）

カメラの向きと放射点の角距離。純粋な幾何計算。

**式③の「高度角」は放射点ではなくカメラを向ける高度である。** 流星は高度約100kmで光るため、
視線距離が `100/sin(高度)` になり、角速度は `ω = v·sin(離角)·sin(カメラ高度)/100` となる。
記事の ω=18°/s は「離角60°・カメラ高度38°」の幾何に相当し
（`asin(18 / ((59/100)·57.3·sin60°)) = 37.94°`）、これを補正の原点にしている。
そのため基準geometryでは補正量がゼロになり、記事の数値がそのまま再現される。

### 空の明るさ（近似値）

自然光（高度約90kmの大気光）と人工光（高度約2kmでの散乱）を別成分として扱い、
それぞれの経路長を van Rhijn 関数で求め、大気減光（0.20等/airmass）をかけて合成する。

```
LPI = 10^(0.4(22.0 - 天頂の空の明るさ)) - 1
空の明るさ(高度) = 22.0 - 2.5·log10(f_自然(高度) + LPI·f_人工(高度))
f(高度) = vanRhijn(高度, 層の高さ) × 10^(-0.4·k·(airmass-1))
```

| カメラの高度 | 大気の厚み | 空の明るさ（暗夜21.6等） | 空の明るさ（郊外18.9等） | 流星の減光 |
|---|---|---|---|---|
| 90° | 1.00 | ±0.00 | ±0.00 | 0.00等 |
| 60° | 1.15 | −0.12 | −0.13 | 0.03等 |
| 45° | 1.41 | −0.28 | −0.29 | 0.08等 |
| 38°（基準） | 1.62 | −0.39 | −0.40 | 0.12等 |
| 30° | 1.99 | −0.52 | −0.55 | 0.20等 |
| 20° | 2.90 | −0.72 | −0.78 | 0.38等 |
| 10° | 5.59 | −0.76 | −0.96 | 0.92等 |

低い方を向くと空が明るくなるうえ流星自身も減光するため**二重に損をする**。
高度10°で増光が飽和して戻るのは、経路が伸びる効果より大気減光が勝つためで、実際の夜空でも起きる挙動。

### 流星自身の減光（近似値）

大気減光係数 0.20等/airmass（晴れた低地の目安）。到達等級と火球の白飛び限界の双方に効く
（減光ぶんだけ火球は「より明るくないと飽和しない」＝白飛びの余裕が増える）。

### 方位による差は含めていない

光害地図は天頂輝度なので、「街の方向を向いたときに空がどれだけ明るいか」は地点の値からは求められない。
周囲の光源分布から Walker則（寄与 ∝ 距離^−2.5）で推定する試作を検証したところ、
小石原川ダム（久留米＝南西・福岡市＝西北西を正しく検出）と輝北天球館（鹿児島市＝西〜北西）では
当たったが、野辺山では諏訪・松本の方向を最暗と誤判定した。地形の遮蔽を無視するためで、
数値として足し込むのは避けた。**同じ高度なら方位によらず同じ空の明るさになる。**

## 赤道儀で追尾する場合

「赤道儀」をオンにすると、日周運動で星が伸びる制約（NPF則）が露出の上限から外れる。
代わりに追尾精度やバッテリーなどの実務的な上限をユーザーが指定する（既定30秒）。

**重要**: 流星は移動天体なので、露出を延ばしても流星の信号は増えず背景だけ増える。
到達等級は露出2倍ごとに 0.38等 悪化するため、追尾しても「長ければ良い」わけではない。
長い露出が有利なのは、コマの切れ目で火球が途切れる確率が下がる点だけである。

基準構成（α7R V + SIGMA 20mm F1.4・小石原川ダム）での比較:

| 目的 | 固定撮影 | 赤道儀（上限30秒） |
|---|---|---|
| 火球狙い | 8秒 / 到達+1.88等 / 収まる67% | **30秒** / 到達+1.21等 / 収まる**90%** |
| バランス | 8秒 / 到達+1.89等 / 収まる67% | 13秒 / 到達+1.65等 / 収まる79% |
| 本数狙い | 2.5秒 / 到達+2.39等 / 収まる14% | **2.5秒（変化なし）** |

本数狙いでは固定撮影でも NPF則の上限に達していないため、**追尾しても設定は変わらない**。
効果があるのは火球狙い寄りの設定に限られる。

## 記事から確定できず、こちらで決めた前提

1. **到達等級の絶対値アンカー**
   記事の「20mm F1.4 でペルセウス座平均(+1.63等)に到達するには空 21.0等が必要」を
   アンカーにした。この前提で空 21.5等では +1.88等となり、記事の「+1.90等」とほぼ一致する。

2. **S/N の式**
   記事の式④は `S/N ∝ 有効口径 / (角速度 × トレイル幅 × √(空の明るさ × 露出時間))`。
   読み出しノイズを扱えるよう `√(空の明るさ×露出時間)` を実際の1画素ノイズ
   `σ = √(背景電子数 + 読み出しノイズ²)` に置き換え、単位を合わせて
   `S/N ∝ D × (画素ピッチ/F値) / (角速度 × トレイル幅 × σ)` としている。
   この形で記事の条件補正表がすべて再現される。既定ではこの式を使い、
   「記事の式のみ」に切り替えると読み出しノイズを無視した式⑤そのままで計算する
   （露出8秒前後では差はほぼゼロ、1秒では 0.32等 の差）。

3. **トレイル幅**
   焦点距離を変えても秒角でのトレイル幅は変えない。これにより記事の
   「焦点距離2倍で +0.75等」がそのまま再現される。ピント精度の影響は係数で与える
   （1.00 = 記事の中央 1.73px、1.63 = 記事の周辺 2.82px）。

4. **背景電子数のスケール定数**
   記事の火球白飛び限界 −4.25等 から逆算した。結果として 15.4 e-/画素
   （空21.0等・8秒・F1.4・3.756µm）となり、読み出しノイズ 1.41 e- に対して
   背景ショットノイズ支配（記事の主張と一致）。

5. **推奨ISO**
   「到達等級の損失が許容値未満に収まる最も低いISO」を選ぶ。火球狙い（許容 0.02等）で
   基準構成は ISO 640 となり記事の推奨値と一致する。

6. **推奨露出**
   NPF則（簡易式）を上限に、目的別スコアを実用シャッター速度の中で最大化する。
   火球狙い＝稼働率 × 途切れない確率／本数狙い＝r^到達等級 × 稼働率／バランス＝両者の対数の平均。

## 光害地図の仕組みと確度

配布タイルは 4bit パレット PNG（16色）で、16色が光害ゾーン
`0 / 1a / 1b / 2a / 2b / 3a / 3b / 4a / 4b / 5a / 5b / 6a / 6b / 7a / 7b / 8` に対応する。
著者の定義（ゾーン+1で人工光3倍、a→bで√3倍、3b/4a境界で人工光=自然光、自然光=22.0等）から

```
LPI（人工光/自然光）= 3^((zone番号-7)/2)   … 帯の下端。zone 4a を index 7 とする
空の明るさ = 22.0 - 2.5·log10(1 + LPI)     … 代表値は帯の対数中央
```

で等級に換算している。

**実装上の注意**: PNG のパレット並び順は**タイルごとに異なる**（エンコーダがタイル単位で
最適化するため）。したがってパレットの index をそのまま使ってはならず、
**RGB値を参照パレット16色と照合して**ゾーンを決めている（`lightpollution.js` の `nearestIndex`）。
一部の外洋タイルは 4bit グレースケール（colortype=0）で、階調は 0 と 34 のみ
＝参照パレットの `#000000`（zone 0）と `#222222`（zone 1a）に一致する。
著者のビューアが欠損タイルを最暗色で描くのと同様に、存在しないタイルは zone 0 として扱う。

### 階調の粗さ

16段階は人工光の対数等分なので、**暗い空ほど細かくなる**。

| 空の領域 | 1段の幅 |
|---|---|
| 21.9〜22.0等 | 0.03〜0.05等 |
| 21.2〜21.7等（好条件の山） | 0.18〜0.26等 |
| 都市部（17〜19等） | 0.55〜0.59等 |

アプリの感度は「空1等 → 到達等級0.5等」なので、狙う暗い空の領域では
到達等級への影響は 0.1等 未満。

### 対象範囲

北緯20〜46度、東経122〜154度（日本周辺）。範囲外では手動設定を促す。
z=6（約500m/px）で同梱しているが、元データの解像度は 1/120度（約925m）なので十分。

## データの確度

- **画素ピッチ**: メーカー公表スペック（センサー実寸 ÷ 有効画素数）から算出。正確。
- **飽和電子数**: α7R V のみ記事の実測値。他機種は α7R V の実測値（2540 e-/µm²）を
  外挿した**推定値**。誤差1段で火球の白飛び限界が ±0.75等 ずれるが、
  **到達等級・推奨露出・推奨ISOには影響しない**。UI 上で「推定」バッジを表示し、手入力もできる。
- **読み出しノイズ**: α7R V の ISO640 実測値 1.41 e- に合わせたモデル
  `σ_r = √((A·100/ISO)² + F²)`。他機種の係数は推定。
- **流星群**: 放射点・対地速度・ZHR・光度分布指数 r は IMO の Working List 相当。
  平均光度は記事のペルセウス座 +1.63等 を基準に一定量オフセットして揃えた便宜的な値。
- **遭遇本数**: 絶対本数は較正できないため、基準構成を 100 とした相対指数のみ表示。
- **天文計算**: 低精度アルゴリズム（太陽 ±0.01°、月 ±0.3°）。設定判断には十分。
  日時は端末のタイムゾーンで解釈する。
