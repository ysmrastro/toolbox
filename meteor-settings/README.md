# 流星撮影セッティング

機材構成・流星群・撮影目的を選ぶと、理論に基づいた露出時間・F値・ISO と、その設定で
写せる暗さ（到達等級）・火球を白飛びさせない限界・1コマに収まる確率を算出する Web アプリ。

- URL: https://ysmrastro.github.io/toolbox/meteor-settings/
- フレームワーク不使用の静的ファイルのみ。GitHub Pages で動作。
- PWA 対応（ホーム画面に追加してオフラインでも動く）。撮影地が圏外でも使える。

## 出典とクレジット

計算は **friend_camera** 氏の記事
[「流れ星の撮り方｜F値とISOを『理論』で決めるペルセウス座流星群の撮影設定ガイド」](https://note.com/brave_godwit4798/n/n938a74b50144)
の付録A（8つの計算式）と本文の各表をそのまま実装したもの。**著者の許諾を得て公開**している。

理論・数値の考案はすべて原著者によるもので、本ツールはその計算を機材構成・流星群・
撮影目的に一般化して自動化したもの。

## 検証

```bash
node meteor-settings/selftest.js
```

基準構成（α7R V + SIGMA 20mm F1.4 / 8秒 / ISO 640 / 空 21.0等 / 角速度 18°/s）で、
記事の以下の数値を再現することを確認している。

| 項目 | 記事 | 本実装 |
|---|---|---|
| NPF則の露出上限 | 8.08秒 | 8.08秒 |
| 到達等級 | +1.63等 | +1.63等 |
| 火球の白飛び限界 | −4.25等 | −4.25等 |
| 2秒火球が途切れない確率 | 67% | 67% |
| ISO 1段で失う火球保護 | 0.76等 | 0.76等 |
| F値1段開放 | +0.38等 | +0.376等 |
| 焦点距離2倍 | +0.75等 | +0.753等 |
| 露出2倍 | −0.38等 | −0.376等 |
| 空が1等明るい | −0.50等 | −0.500等 |
| ピント（中央→周辺） | −0.53等 | −0.530等 |
| 角速度2倍 | −0.75等 | −0.753等 |

また、目的「火球狙い」で推奨設定を探索させると **8秒 / ISO 640** が選ばれ、記事の推奨設定と一致する。

アプリ内の「記事の数値との突き合わせ」カードでも、ユーザー入力とは無関係に基準構成を
固定値で計算した結果を記事の数値と並べて表示している。

## 記事から確定できず、こちらで決めた前提

1. **到達等級の絶対値アンカー**
   記事の「20mm F1.4 でペルセウス座平均(+1.63等)に到達するには空 21.0等が必要」を
   アンカーにした。この前提で空 21.5等では +1.88等となり、記事の「+1.90等」とほぼ一致する。

2. **S/N の式**
   記事の式④は `S/N ∝ 有効口径 / (角速度 × トレイル幅 × √(空の明るさ × 露出時間))`。
   読み出しノイズを扱えるよう `√(空の明るさ×露出時間)` を実際の1画素ノイズ
   `σ = √(背景電子数 + 読み出しノイズ²)` に置き換え、単位を合わせて
   `S/N ∝ D × (画素ピッチ/F値) / (角速度 × トレイル幅 × σ)` としている。
   この形で記事の条件補正表がすべて再現される。既定ではこの式を使い、
   「記事の式のみ」に切り替えると読み出しノイズを無視した式⑤そのままで計算する
   （露出8秒前後では差はほぼゼロ、1秒では 0.32等 の差）。

3. **トレイル幅**
   焦点距離を変えても秒角でのトレイル幅は変えない。これにより記事の
   「焦点距離2倍で +0.75等」がそのまま再現される。ピント精度の影響は係数で与える
   （1.00 = 記事の中央 1.73px、1.63 = 記事の周辺 2.82px）。

4. **背景電子数のスケール定数**
   記事の火球白飛び限界 −4.25等 から逆算した。結果として 15.4 e-/画素
   （空21.0等・8秒・F1.4・3.756µm）となり、読み出しノイズ 1.41 e- に対して
   背景ショットノイズ支配（記事の主張と一致）。

5. **推奨ISO**
   「到達等級の損失が許容値未満に収まる最も低いISO」を選ぶ。火球狙い（許容 0.02等）で
   基準構成は ISO 640 となり記事の推奨値と一致する。

6. **推奨露出**
   NPF則（簡易式）を上限に、目的別スコアを実用シャッター速度の中で最大化する。
   火球狙い＝稼働率 × 途切れない確率／本数狙い＝r^到達等級 × 稼働率／バランス＝両者の対数の平均。

## データの確度

- **画素ピッチ**: メーカー公表スペック（センサー実寸 ÷ 有効画素数）から算出。正確。
- **飽和電子数**: α7R V のみ記事の実測値。他機種は α7R V の実測値（2540 e-/µm²）を
  外挿した**推定値**。誤差1段で火球の白飛び限界が ±0.75等 ずれるが、
  **到達等級・推奨露出・推奨ISOには影響しない**。UI 上で「推定」バッジを表示し、手入力もできる。
- **読み出しノイズ**: α7R V の ISO640 実測値 1.41 e- に合わせたモデル
  `σ_r = √((A·100/ISO)² + F²)`。他機種の係数は推定。
- **流星群**: 放射点・対地速度・ZHR・光度分布指数 r は IMO の Working List 相当。
  平均光度は記事のペルセウス座 +1.63等 を基準に一定量オフセットして揃えた便宜的な値。
- **遭遇本数**: 絶対本数は較正できないため、基準構成を 100 とした相対指数のみ表示。
- **天文計算**: 低精度アルゴリズム（太陽 ±0.01°、月 ±0.3°）。設定判断には十分。
  日時は端末のタイムゾーンで解釈する。
