# 光軸合わせシミュレーター（ニュートン式・BKP130）

https://ysmrastro.github.io/toolbox/collimation/

ネジを1本ずつ動かして、センタリングアイピースで覗いた景色がどう変わるかを確かめる。
フレームワークもビルドも通信もなし。`index.html` / `style.css` / `app.js` の3枚。

## 画面

| ペイン | 中身 |
|---|---|
| センタリングアイピースの視野 | 覗いた景色。左が筒先側、右が主鏡側 |
| 筒の断面 | 斜鏡の位置と角度。覗き穴から出した視線が、戻ってきたときどれだけ外れるかも出す |
| 斜鏡を面の正面から | 鏡の楕円と、主鏡から来る光の切り口 |
| 土台をドローチューブ側から | 45°に切った柱の先に、鏡が中心をずらして貼ってある姿 |
| 調整パラメータ | まんなかが合っている状態。数字をタップすると 0 に戻る |
| いま測るとこうなる | 層ごとの偏心。主鏡の見かけの半径に対する% |

スマホでは**上の絵が画面に貼りつき**、タブで3枚を切り替える。下でつまみを動かしても絵が見える。

つまみは**折りたためる3つの塊**に分けてある。ふだんさわる順に、斜鏡まわり → 主鏡の押しネジ →
ドローチューブ。**ドローチューブは基本さわらないので、一番下で畳んである。**
畳んだ塊の中に 0 でないつまみが残っていたら、見出しの右に印（`●` と本数）を出す
── **畳んだせいでズレを見落とさないため。**

**「ずれ方」のボタンは、型であって固定値ではない。**押すたびに、その型のなかで別のずれを作る
（向きは一様に、大きさは型ごとの範囲から）。ネジ3本のずれは `tiltScrews()` が
`d_i = A·cos(θ_i − φ)` で作るので、**前後（piston）は動かず傾きだけが出る。**
どのボタンが光るかは最後に押したものを覚えておくやり方で、**つまみを手で動かすと外れる**
（「完全に合っている」だけは、つまみが全部 0 かどうかで判断する）。

### 土台のペイン

**土台は「ステム軸に沿った円柱を 45°で切ったもの」として描く。**円柱の半径を斜鏡の短半径に
とれば、切り口はちょうど鏡の楕円になる（長半径＝短半径×√2）。だから**本体の太さには
仮定がいらない。**仮の値は `HOLD_L`（本体の長さ 28mm）と `STEM_R`（柱の半径 4.5mm）だけで、
どちらも絵のためだけのもの。

**真正面から見ると、柱の回転がまったく見えない。**土台はステム軸のまわりに対称なので、
輪郭が変わらないからである。そこで **15° だけ斜めから**見ている（`STEM_TILT`）。
斜めにすると鏡の楕円がはっきりした形を持つので、**回転がその向きの傾きとして読める**。
合っているときの鏡を点線で重ねてあるので、わずかな回転でもそこからのずれで分かる。

`geometry()` は描画用に `stem` を返す。**計算そのものは変えていない**
（合っているときの読み取りは 0.00% / 0.00% / 3.81% のまま）。

## モデル

**覗いている目を、斜鏡の面で折り返した点 E₁ をひとつ作る。**あとは全部の層を「展開した空間」に
置いて、E₁ から投影するだけで済む。

| 層 | 展開した空間での置き方 |
|---|---|
| 0回（ドローチューブの縁・斜鏡の鏡面の縁） | 物体を斜鏡の面で折り返したもの |
| 1回（主鏡の縁・爪・センターマーク） | 物体そのもの |
| 2回（斜鏡のシルエット・スパイダー） | 主鏡が結んだ像 |
| 3回（アイピースの裏側・覗き穴） | 斜鏡で折り返してから、主鏡が結んだ像 |

斜鏡は**平面の鏡として厳密に**、主鏡は**近軸の凹面鏡**（f=650mm）として扱っている。

3回反射の像は**目より先に結ぶ実像**になる（目は収束の途中の光を受けている）ので、
投影では光線の向きを裏返して、来た方向を見かけの位置にしている。
**これを忘れると 3回反射の層がまるごと描かれない。**

## 構造 ── オフセットはどこで作るか

**スパイダーの4本は均一に張ってあり、台は筒の中心軸の上にある。**
オフセットはスパイダーで作るものではなく、**鏡を土台のどこに貼るか**で作る ──
土台の軸から、面に沿って主鏡側へ `OFFSET` だけずらして貼ってある、という形にしてある。
だから**貼り付けの向きが回ると、オフセットの向きも一緒に回る。**

最初はオフセットをスパイダーの台ごと寄せて作っていた。それだと**スパイダーの交点（2回反射）が
主鏡の中心から 4% 以上外れる**。構造どおりなら 0%。

斜鏡の押しネジ3本と引きネジ1本は、**ステム軸（＝筒の中心軸）に沿って**効く。
3本を同じだけ回しても傾かず、前後に動くだけ。

**「斜鏡の回転」は、中央の引きネジをゆるめて土台の柱ごと回す動き。**
45° に切った面がまるごと回るので、鏡の法線が円錐を描いて振れる ── 楕円の向きだけが
変わるのではなく、**視野そのものが動く。**1° で主鏡の像が視野の 12.8% ずれる。
だから範囲は ±6°。**傾きを合わせる前に決めるもの**、という順番がここに出る。

## 数値の前提 ── 確かなのは口径と焦点距離だけ

`app.js` の `P` にまとめてある。**実機を測ったらここだけ差し替えればいい。**

| 記号 | いまの値 | 何か |
|---|---|---|
| `R_PM` / `F_PM` | 65 / 650 | 主鏡の半径・焦点距離。**ここだけが確か** |
| `SEC_A` / `SEC_B` | 31.82 / 22.5 | 斜鏡の長半径・短半径（短径 45mm）。**根拠なし** |
| `L` | 460 | 交点の z（＝650 − 交点から焦点面まで 190）。**未実測** |
| `OFFSET` | 2.714 | オフセット。`L` から決まる従属値 |
| `D_FIELD` | 46 | ドローチューブの先の、交点からの距離（繰り出し 0 のとき）。**未実測** |
| `R_FIELD` | 25.4 | ドローチューブの縁の内半径。2インチは差込口の呼び径なので、実際の開口はもう少し大きいかもしれない |
| `EPB_R` / `EPB_H` | 9.52 / 4.03 | アイピースの裏側と覗き穴の半径。**未実測** |

**目を置く位置の基準は焦点面**（`FOCAL = F_PM − L` = 交点から 190mm）。つまみの中央がここ。
実際にはセンタリングアイピースの長さぶん外側から覗くことになるが、**その長さは人によって
違うのでモデルに入れていない。**繰り出すと目の位置とドローチューブの先が一緒に動く
（視野の広さは変わらない ── 両者の距離が変わらないため）。

`OFFSET` は `L` から決まる従属値なので、**`L` を変えたら必ず一緒に直す。**
ページ側は `OFFSET_IDEAL` を起動時に二分法で解いて表示するので、ずれていれば画面に出る。

**絵の中の比率はこれらの値しだいで変わる。**このページで確かなのは、
**どのネジを回すとどの層が動くか**という関係のほう。

## 検算

幾何が正しく組めているかは、手で解ける値と突き合わせてある。

| | このページ | 手計算 |
|---|---|---|
| 切り口が鏡の中心に来るオフセット | 2.714mm | 2.714mm |
| 光の切り口／斜鏡（長軸） | 0.8530 | 0.8530 |
| 光の切り口／斜鏡（短軸） | 0.8487 | 0.8487 |
| 鏡の余り | 長軸の端 4.68mm ／ 短軸の端 3.40mm | 同左 |

**数値をいじったらここを必ず再確認する。**

読み取りは重心ではなく**円のあてはめ**で出している。射影された楕円は点の並びが偏るので、
重心を中心にすると斜鏡の縁の偏心が化ける（3.08% → 9% 台）。

## 近似の限界

- 主鏡を近軸で扱っているので、視野の端のほうの 2回・3回の像はわずかに歪む
- **返ってくる像（3回）の大きさ**は、覗き穴の距離と裏側の寸法で決まる。どちらも仮の値なので、
  実機と同じ大きさにはならない。**位置のほうは安定している**ので、光軸合わせの話には影響しない
- 主鏡の押しネジは**傾きだけ**を効かせている。3本を同じだけ回すと本当はピントが前後するが、
  それをやると 3回反射の像の大きさが暴れて見づらいので入れていない
- 斜鏡の土台の柱は、ステム軸が筒の中心軸と平行だとしている（Synta 型の想定）
