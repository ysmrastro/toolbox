# 光軸合わせシミュレーター（ニュートン式・BKP130）

https://ysmrastro.github.io/toolbox/collimation/

ネジを1本ずつ動かして、センタリングアイピースで覗いた景色がどう変わるかを確かめる。
フレームワークもビルドも通信もなし。`index.html` / `style.css` / `app.js` の3枚。

## 画面

| ペイン | 中身 |
|---|---|
| センタリングアイピースの視野 | 覗いた景色。左が筒先側、右が主鏡側（実写と同じ向き） |
| 筒の断面 | 斜鏡の位置と角度。覗き穴から出した視線が、戻ってきたときどれだけ外れるかも出す |
| 斜鏡を面の正面から | 鏡の楕円と、主鏡から来る光の切り口 |
| 調整パラメータ | まんなかが合っている状態。数字をタップすると 0 に戻る |
| いま測るとこうなる | 層ごとの偏心。主鏡の見かけの半径に対する% |

スマホでは**上の絵が画面に貼りつき**、タブで3枚を切り替える。下でつまみを動かしても絵が見える。

## モデル

**覗いている目を、斜鏡の面で折り返した点 E₁ をひとつ作る。**あとは全部の層を「展開した空間」に
置いて、E₁ から投影するだけで済む。

| 層 | 展開した空間での置き方 |
|---|---|
| 0回（ドローチューブの縁・斜鏡の鏡面の縁） | 物体を斜鏡の面で折り返したもの |
| 1回（主鏡の縁・爪・センターマーク） | 物体そのもの |
| 2回（斜鏡のシルエット・スパイダー） | 主鏡が結んだ像 |
| 3回（アイピースの裏側・覗き穴） | 斜鏡で折り返してから、主鏡が結んだ像 |

斜鏡は**平面の鏡として厳密に**、主鏡は**近軸の凹面鏡**（f=650mm）として扱っている。

3回反射の像は**目より先に結ぶ実像**になる（目は収束の途中の光を受けている）ので、
投影では光線の向きを裏返して、来た方向を見かけの位置にしている。
**これを忘れると 3回反射の層がまるごと描かれない。**

## 構造 ── オフセットはどこで作るか

**スパイダーの4本は均一に張ってあり、台は筒の中心軸の上にある。**
オフセットはスパイダーで作るものではなく、**鏡を土台のどこに貼るか**で作る ──
土台の軸から、面に沿って主鏡側へ `OFFSET` だけずらして貼ってある、という形にしてある。
だから**貼り付けの向きが回ると、オフセットの向きも一緒に回る。**

最初はオフセットをスパイダーの台ごと寄せて作っていた。それだと**スパイダーの交点（2回反射）が
主鏡の中心から 4.4% 外れる**。実測は 1.68%（ほぼ中心）なので、構造が違うとすぐ分かる。

斜鏡の押しネジ3本と引きネジ1本は、**ステム軸（＝筒の中心軸）に沿って**効く。
3本を同じだけ回しても傾かず、前後に動くだけ。

## 合っている状態を実測と照合した

| | モデル | 実測 |
|---|---|---|
| 斜鏡の縁／主鏡の縁 の大きさ比 | 1.149 | 1.153 |
| 斜鏡の縁の偏心 | 1.45%（主鏡側） | 1.31%（主鏡側） |
| 斜鏡のシルエットの偏心 | 4.36%（主鏡側） | 4.73%（主鏡側） |
| シルエットの見かけ半径 | 35.4% | 35.4% |
| スパイダーの交点 | 0.00% | 1.68% |
| 輪の太さ（太い側／細い側） | 1.21 倍・太いのは主鏡側 | 1.29 倍・太いのは主鏡側 |

実測は BKP130 の実写（光軸を合わせた状態）に円をあてはめて出したもの。
**値をいじったらここを必ず再確認する。**

読み取りは重心ではなく**円のあてはめ**で出している。射影された楕円は点の並びが偏るので、
重心を中心にすると斜鏡の縁の偏心が 1.45% → 7.90% に化ける。

## まだ実測できていない仮定値

`app.js` の `P` にまとめてある。**実機を測ったらここだけ差し替えればいい。**

| 記号 | いまの値 | 何か |
|---|---|---|
| `L` | 472 | 交点の z（＝650 − 交点から焦点面まで 178mm） |
| `EYE` | 199 | 覗き穴の、交点からの距離 |
| `OFFSET` | 3.95 | オフセット（面に沿って、主鏡側へ） |
| `EPB_R` / `EPB_H` | 9.52 / 4.03 | アイピースの裏側（銀の面）と覗き穴の半径 ── 実写の見え方から逆算した値 |

`EPB_R` / `EPB_H` は `EYE` を変えると辻褄が合わなくなる。**3つはセットで測り直すこと。**

## 近似の限界

- 主鏡を近軸で扱っているので、視野の端のほうの 2回・3回の像はわずかに歪む
- **返ってくる像（3回）の大きさ**は、覗き穴の距離にとても敏感。焦点のすぐ外側に物体があるため。
  実写でも撮るたびに変わっている。**位置のほうは安定している**ので、光軸合わせの話には影響しない
- 主鏡の押しネジは**傾きだけ**を効かせている。3本を同じだけ回すと本当はピントが前後するが、
  それをやると 3回反射の像の大きさが暴れて見づらいので入れていない
- 斜鏡の回転は**鏡の貼り付けの向き**（面の中の回転）として入れてある。
  土台ごとステム軸のまわりに回すと鏡の法線も振れるが、そちらは未実装
