# 鳩メーカー（試作）

体の大きさ・胴まわり・脚の長さ・首・頭などを変えて、好きなドバト（*Columba livia*）を作る。
横向きの SVG を JS で組み立てる（外部ライブラリなし）。個体番号（1〜9999）から同じ鳩を呼び出せる。

発想は、たぬきメーカー（@TanukiUkulele 氏のツイート）の鳩版。元は 3D モデルだが、ここは静的 HTML なので横向きの 2D で描く。

## 寸法の根拠

| 項目 | 値 | 出典 |
|---|---|---|
| 翼長 | 平均 221.4mm（範囲 200–237） | Acta Vet Scand 2010;52:45 表1（Madrid の市街地ドバト n=118） |
| 跗蹠長 | 平均 31.6mm（範囲 27.2–36.3） | 同上 |
| 体重 | 平均 275.6g（範囲 168–385） | 同上 |
| 全長 | 約 33cm（29–37cm の中ほど） | 二次資料（Wikipedia・BirdForum・HBW を引く Oiseaux-birds） |
| 羽色の型 | 白 / ブルーバー / チェッカー / T パターン / スプレッド | Johnston & Janiga (1995)。Aouissi et al. 2021 Avian Res 12:45 が引用 |

- スライダーの既定の範囲は、上の実測の範囲に収めている（`pigeon.js` の `PARAMS` の `real`）。
  「ありえない個体も作る」を入れると `fun` の範囲まで広がる。そのときは体が画面からはみ出したり、
  脚が短すぎて体が地面にめり込んだりする（意図した動き）。
- 「胴まわり」の範囲は、体の大きさに応じて変わる（`girthRange`）。体重は 大きさ³ × 胴まわり² なので、
  どちらも範囲の端にすると体重が 168–385g を外れるため、大きさごとに胴まわりの上下限を決めている。
- 全長（29–37cm）は、尾・首・頭などの「仮」のスライダーも関わるので、スライダーの端どうしを組み合わせると外れる
  （27〜39cm）。範囲に収まる保証は、個体番号から決めるときだけにある。
- 個体番号から決めるときは、体重 168–385g・全長 29–37cm に収まるまで同じ番号から引き直す
  （番号が同じなら結果も同じ。1〜9999 の全部がテストで範囲内）。
- 「体の大きさ」は翼長が平均の何倍か。体重は `275.6g × 大きさ³ × 胴まわり²`（**この式は私の仮定**。
  翼長が同じでも体重が 168–385g に散るので、その差を「胴まわり」に持たせている）。
- 画面の「文献」の印は文献の範囲に収めたもの、「仮」の印は文献値を取れていないもの。

## 仮の値（文献値を取れていない）

**尾の長さ・くちばしの長さ・首の長さ・頭の大きさ・目の大きさ・脚の太さ・胴の長さ**は、見た目の釣り合いから置いた仮の値。
Aouissi et al. 2021（Avian Res 12:45）の Table 1 に尾長・culmen・趾・総長の記述統計があるが、
表の数値は取得できていない。取れたら `pigeon.js` の `geom()` の定数と `PARAMS` の `real` を置き換える。

縮尺は 1mm = 1.25px（`U`）。

## 構成

- `pigeon.js` — 寸法・個体の決め方・SVG の組み立て・動き（DOM に触らない）
- `app.js` — スライダー・ボタン・アニメーションの駆動、画像保存、設定のコピーと読み込み（読み込みは `parseSettings` で検査してから取り込む）
- `ogp-source.html` — OGP 画像の生成元（実物の `pigeon.js` で描く）
- `test/pigeon.test.js` — 文献の数値と範囲、個体番号の再現性、描画が壊れないこと

## 描き方の工夫

- 絵は3層を重ねている: 背景と脚（SVG）／体（画像）／首と頭（SVG）。
  体は羽が約1700本の path になり重いので、動かさない。歩くときは足・首・頭だけを毎フレーム書き換える。
- **体は画像にして貼る**（`app.js` の `bodyImage`）。SVG のまま画面サイズで描くと、スマホ（特に Safari）で
  描画が低解像度になり、引き伸ばされて粗く見える。`devicePixelRatio` に合わせた大きさの画像にしている。
- **体に `feDisplacementMap`（ふちを乱すフィルタ）をかけない。** webkit では羽がざらざらに潰れて、
  粗い画像のように見えた（フィルタあり／なしを webkit で並べて確かめた）。縁は羽そのものに任せている。
- 羽は1枚ずつ描く。体は輪郭羽を屋根瓦のように重ね（後ろ・下から先に、前・上を後に）、
  翼は初列・次列風切と大・中・小雨覆、尾は12枚の尾羽。ブルーバーの帯は、大雨覆と次列風切の羽先の暗色。
- 首の玉虫色は、羽1枚ごとに緑・青緑・紫を付けている（`neckTex`）。首の下端と胸の前縁は体の色に溶かす。
- 首・頭の層は SVG フィルタを使わない。要素数も体より少なくする（首・頭の羽は軸とハイライトを省く）。
- 歩くときの頭の動きは、体が進む間は頭を世界に固定し、そのあと素早く前へ出す（ハトの首振り）。
  首の羽は頭と一緒に後ろへ寄るので、前側に約20s 余分に羽を置いて隙間を埋めている。
