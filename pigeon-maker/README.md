# 鳩メーカー（試作）

体の大きさ・胴まわり・脚の長さ・首・頭などを変えて、好きなドバト（*Columba livia*）を作る。
横向きの SVG を JS で組み立てる（外部ライブラリなし）。個体番号（1〜9999）から同じ鳩を呼び出せる。

発想は、たぬきメーカー（@TanukiUkulele 氏のツイート）の鳩版。元は 3D モデルだが、ここは静的 HTML なので横向きの 2D で描く。

## 寸法の根拠

| 項目 | 値 | 出典 |
|---|---|---|
| 翼長 | 平均 221.4mm（範囲 200–237） | Acta Vet Scand 2010;52:45 表1（Madrid の市街地ドバト n=118） |
| 跗蹠長 | 平均 31.6mm（範囲 27.2–36.3） | 同上 |
| 体重 | 平均 275.6g（範囲 168–385） | 同上 |
| 全長 | 約 33cm（29–37cm の中ほど） | 二次資料（Wikipedia・BirdForum・HBW を引く Oiseaux-birds） |
| 羽色の型 | 白 / ブルーバー / チェッカー / T パターン / スプレッド | Johnston & Janiga (1995)。Aouissi et al. 2021 Avian Res 12:45 が引用 |

- スライダーの既定の範囲は、上の実測の範囲に収めている（`pigeon.js` の `PARAMS` の `real`）。
  「ありえない個体も作る」を入れると `fun` の範囲まで広がる。
- 「体の大きさ」は翼長が平均の何倍か。体重は `275.6g × 大きさ³ × 胴まわり²`（**この式は私の仮定**。
  翼長が同じでも体重が 168–385g に散るので、その差を「胴まわり」に持たせている）。
- 画面の「文献」の印は文献の範囲に収めたもの、「仮」の印は文献値を取れていないもの。

## 仮の値（文献値を取れていない）

**尾の長さ・くちばしの長さ・首の長さ・頭の大きさ・目の大きさ・脚の太さ・胴の長さ**は、見た目の釣り合いから置いた仮の値。
Aouissi et al. 2021（Avian Res 12:45）の Table 1 に尾長・culmen・趾・総長の記述統計があるが、
表の数値は取得できていない。取れたら `pigeon.js` の `geom()` の定数と `PARAMS` の `real` を置き換える。

縮尺は 1mm = 1.25px（`U`）。

## 構成

- `pigeon.js` — 寸法・個体の決め方・SVG の組み立て・動き（DOM に触らない）
- `app.js` — スライダー・ボタン・アニメーションの駆動
- `ogp-source.html` — OGP 画像の生成元（実物の `pigeon.js` で描く）
- `test/pigeon.test.js` — 文献の数値と範囲、個体番号の再現性、描画が壊れないこと

## 描き方の工夫

- 絵は3枚の SVG を重ねている。体（羽毛の鱗・ふちの乱れで負荷が高い）は動かさず、足・首・頭だけを動かす。
- ふちの乱れは `feTurbulence` + `feDisplacementMap`。羽毛のふくらみのスライダーで強さが変わる。
- 首の玉虫色は緑・紫・青緑のぼかしを首の形で切り抜いている。
- 歩くときの頭の動きは、体が進む間は頭を世界に固定し、そのあと素早く前へ出す（ハトの首振り）。
