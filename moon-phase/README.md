# 月の満ち欠けシミュレーター

月をドラッグして軌道上を動かすと、北極から見下ろした図（軌道）と、地球から見た月の形（見え方）が同時に変わる。未就学児を含む家族連れ向けのお話会で使うことを想定し、漢字にはすべてふりがなを付けてある。

## 見え方のモデル

太陽は地球から見て十分に遠く、光はどの位置でも同じ向き（画面の左から右）で当たるとみなしている。この近似の範囲で、次の3つだけで見え方が決まる。

- **月齢 age**（0〜朔望月 `SYN = 29.5306` 日）から、軌道上の角度 `phi = age / SYN * 2π` を作る（新月＝0）
- `phi` は同時に、太陽・地球・月のなす角（離角 E）でもある ── 太陽が無限遠にあるとみなしているので、地球から見た太陽の方向は常に一定（画面の左）であり、地球から見た月の方向の角度がそのまま離角になる
- 月は**北極から見て反時計回り**に動く。`app.js` の `moonPosition()` は
  `x = 中心x - R*cos(phi)`, `y = 中心y + R*sin(phi)` で、`phi=0` が左（新月）、
  `phi=90°` が下（上弦）、`phi=180°` が右（満月）、`phi=270°` が上（下弦）になるように作ってある

### 北極から見下ろした図（左）

地球・月とも「太陽側＝左半分が明るい」固定の絵（`halfDiskPath()`）。月はこの絵のまま、軌道上を位置だけ動く。北半球側からの視点を示す印として、地球の中心に北極を表す白い点を置いている。

### 地球から見た月の形（右）

**北半球の観測者から見た形**にしてある（南半球では左右が逆になる）。

- 満ちていく（`phi` が 0〜180°）ときは**右**から光る、欠けていく（180〜360°）ときは**左**から欠けていく
- 輝面率は `k = (1 - cos(phi)) / 2`（新月0・上弦/下弦0.5・満月1）
- 明暗の境界（ターミネーター）は、月の輪郭（真円の半分）と、半径
  `|r * cos(phi)|` の半楕円を組み合わせて作る（`moonShapePath()`）。
  三日月〜半月〜満月〜有明月のどの形も、この1本の式でつながる
- 暗い側も `--mp-moon-dark` でうっすら塗っている（実際の地球照を厳密に再現したものではなく、「真っ黒にしない」ための見た目上の配慮）

### 実際の暦とは連動しない

月齢はスライダー・ドラッグ・自動再生でその場で動かすだけで、実際の日付とは連動していない（スコープ外）。
